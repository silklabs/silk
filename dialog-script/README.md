# Dialog Script Reference Implementation

## Quickstart

```
$ npm install -g silk-cli
$ git clone git@github.com:silklabs/release-pando-dialog-script.git
$ cd release-pando-dialog-script/
$ npm install
$ silk build
<attach the Silk device to USB>
$ silk push
```

## Luis Models

Luis models are stored on the Luis cloud. A copy of the exported app
is also found in the `./model` directory for convenience.
