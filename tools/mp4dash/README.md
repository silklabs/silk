# MP4 DASH Helpers

This node module contains helpers to generate mp4 files from DASH
segments generated by a Silk device and streamed via socket.io.

## Installation

```
npm install
```

## Configuration

You can configure which Silk server to connect to, which device's
video stream you want to record, and which account to use in
`src/config.js`. For example:

```js
const config = {
  port: 9999,
  serverUrl: 'http://silk-server-master.herokuapp.com/',
  user: 'e@silk.io',
  password: 'raccoon',
  deviceId: '032aa987ce505299f31b5317ecd1ca774e4e9a411ad81bc90aec177b9bd935883b',
};
```

## Concatenating segments into a standalone mp4 file

After editing the configuration file, you can record video to a
single, standalone mp4 file by simply calling
```
npm run cat
```

(or `npm run file`).  This will record to `out.mp4` in your current directory. Stop
recording with Ctrl-C.

## Saving individual segments to file

Alternatively, you can each individual segment sent from device by running
```
npm run segments
```

This commands saves the mp4 "initialization header" to `segments/seg-init.mp4`, and
each successive segment to `segments/seg-%d.m4s`, where the `%d` is replaced with the
segment sequence number, for example `segments/seg-1.m4s`.  Stop recording with Ctrl-C.

## Streaming over HTTP

It is possible to stream the video to an HTTP client. The HTTP server
pretends to serve a very very large mp4 file. Firefox and Chrome deal
with this pretty well and can start playing the file immediately while
continuously receiving more data. Safari and QuickTime can't.

This will start the server and listen on the port specified in
`src/config.js`:
```
npm start
```

You can then point your browser at `http://localhost:9999/default.mp4` or
`http://localhost:9999/<deviceid>.mp4` to stream the video.
