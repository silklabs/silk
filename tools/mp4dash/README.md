# MP4 DASH Helpers

This node module contains helpers to generate mp4 files from DASH
segments generated by a Silk device and streamed via socket.io.

## Installation

```
npm install
```

## Configuration

You can configure which Silk server to connect to, which device's
video stream you want to record, and which account to use in
`src/config.js`. For example:

```js
const config = {
  port: 9999,
  serverUrl: 'http://silk-server-master.herokuapp.com/',
  user: 'e@silk.io',
  password: 'raccoon',
  deviceId: '032aa987ce505299f31b5317ecd1ca774e4e9a411ad81bc90aec177b9bd935883b',
};
```

## Recording to a file

After editing the configuration file, you can recording video to a
file by simply calling

```
npm run file
```

This will record to `out.mp4` in your current directory. Stop
recording with Ctrl-C.

## Streaming over HTTP

It is possible to stream the video to an HTTP client. The HTTP server
pretends to serve a very very large mp4 file. Firefox and Chrome deal
with this pretty well and can start playing the file immediately while
continuously receiving more data. Safari and QuickTime can't.

This will start the server and listen on the port specified in
`src/config.js`:

```
npm start
```
