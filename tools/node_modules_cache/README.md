# Node Modules Cache

This tool is designed to cache `node_module` folders remotely in such a
fashion that they can be referenced by a hash (computed by reading
package.json).

## Uploading

  - Check if package is already on s3 (using the computed hash) if it
    exists abort.

  - We first copy the package.json of the target into a tmp folder.

  - Run `npm install --ignore-scripts` (lifecycle hooks are ignored so
    we do not end up /w platform specific deps in cache).

  - Create a tar of the `node_modules` folder output (along /w a file to
    track cache metadata).

  - Tar is uploaded to s3 using the hash computed from the package.json
    dependencies.

## Downloading

  - Compute current hash for package.json and check if `node_modules`
    folder contains the hash metadata. If the hash matches abort.

  - Check s3 for package (using the computed hash).

  - Download tar from cloudfront (CDN for best performance).

  - Expand tar into tmp folder and run `npm rebuild` (compile platform
    specific targets)

  - Remove any conflicting dependencies from target `node_modules`
    folder.

  - `mv` dependencies from the tmp folder into target `node_modules`.
